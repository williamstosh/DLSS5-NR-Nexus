# NR Nexus v0.6.2 — DX11 帧率与 XeFG 切换修复 / DX11 performance and XeFG switching fixes

<!-- Previous: v0.6.1 -->

[简体中文](#简体中文) · [English](#english)

## 简体中文

### 版本亮点

修复部分 DX11 游戏在使用普通 Present 模式、关闭帧生成时基础帧率偏低的问题，也改善了游戏中重新开启 XeFG 时的画面交接。升级后无需新增设置。

### 修复内容

- 普通 DX11 Present 不再每帧在 CPU 上等待 NR 的 GPU 工作。画面仍按原有顺序输出。
- 开启 XeFG 时，沿用同一运行时不再等待无关的旧帧。确实需要切换运行时时，只在已提交的旧帧完成后接管，避免丢失新帧或重复增强同一画面。
- 改善 XeFG 场景切换和连续帧生成时的颜色交接；本插件自己保留的当前帧深度和运动矢量可以在有效时使用。

### 验证情况

此前的本地集成版在《最终幻想 XV》4K、双 Pass 的定向实机中恢复了关闭帧生成时的基础帧率，再次开启 XeFG 后恢复 4×。该实机用的是本地验证版，不是此页下载的 ZIP。正式发布源码另做普通与 DEV 两种构建的 WARP 回归，覆盖相邻帧画面顺序、XeFG 热切、失败后的回退，以及旧 GPU 工作未完成时的资源保留。

### 已知限制

此处的实机结论限于上述 DX11 场景。首次启用 XeFG 时，新运行时或模型可能需要短暂准备。动态画质和主观流畅度未在本版本重新验收。

### 安装说明

下载 Windows x64 ZIP 和相应的 `.zip.sha256` 并校验。退出游戏，备份原插件和设置，替换 `renodx-dlss5.addon64`，避免同时加载两个版本。包内含双语 README、使用指南、离线 HTML 手册和许可证。支持完整 Add-on/API 18 的 ReShade 及兼容的 NVIDIA NR Runtime 需另行准备。

## English

### Highlights

Fixed unexpectedly low base FPS in some DX11 games using ordinary Present with frame generation off. Switching XeFG back on in game now hands off frames more reliably. No new settings are required.

### Fixes

- Ordinary DX11 Present no longer waits on the CPU every frame for NR's GPU work. Frames still reach the output in the original order.
- Re-enabling XeFG with the same runtime no longer waits for unrelated older frames. A genuine runtime switch takes over only after previously submitted work finishes, avoiding dropped frames or duplicate edits.
- Improved color handoff on XeFG transitions and consecutive generated frames. The add-on can now use its own current-frame depth and motion vectors when those inputs remain valid.

### Validation

A targeted 4K, dual-pass test of an integrated local build in FINAL FANTASY XV restored base FPS with frame generation off and resumed 4× output after re-enabling XeFG. That test used a local validation build, not the ZIP on this page. The release source separately runs standard and DEV WARP regressions for adjacent-frame ordering, XeFG transitions, failure recovery and retention of resources while old GPU work is still pending.

### Known Limitations

The in-game result above applies to that DX11 scenario. Enabling XeFG for the first time can still need a short runtime or model setup. Dynamic image quality and perceived smoothness were not re-evaluated for this release.

### Installation

Download and verify the Windows x64 ZIP and its `.zip.sha256`. Close the game, back up your add-on and settings, and replace `renodx-dlss5.addon64`. Avoid loading two versions. The package includes a bilingual README, user guide, offline HTML manual and licenses. ReShade with full Add-on/API 18 support and a compatible NVIDIA NR Runtime are separate requirements.
