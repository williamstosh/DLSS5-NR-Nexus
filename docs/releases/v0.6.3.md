# NR Nexus v0.6.3 — 运行时、XeFG 与监视器修复 / Runtime, XeFG and monitor fixes

## 简体中文

### 版本亮点

普通 Present 和 XeFG 路径改为复用原签名 NVIDIA NR 运行时，不再为这两条路径在游戏目录逐次创建私有 DLL 副本。也改善了菜单、载档和过场中的 NR 接续，以及监视器和问题报告显示的当前输出状态。升级无需新增设置。

### 修复内容

- 《如龙8》这类使用可选引导的 XeFG 菜单切换，在创建条件不变时保留已准备的 NR 模型。切回游戏时继续使用当前帧；真实的游戏历史重置照常执行。
- 《最终幻想 XV》启动时，XeFG 刚接管但还没有首帧结果，提示保持灰色「准备 NR」；实际拒绝或提交失败仍会提示。载档期间，真实引导和备用引导在条件相同时复用模型，减少原画和 NR 反复切换的诱因。
- 《黑手党：最终版》的 DX11 普通 Present 兼容了部分没有引导的过场，在场景合成后处理当前画面，保留其后的叠层。
- 监视器按选中的输出及实际交付结果显示 NR。问题报告保留点击收集时的窗口和状态，之后切换窗口不会串入别的结果。
- 等效的模型参数变动不再重置画面历史；Direct3D 和 Vulkan 的区域遮罩沿用一致的深度和运动计算。Vulkan 保留旧录制重放所需的资源，直到对应录制真正结束。

### 验证情况

本版本的发布流程对准确的源码和 Windows x64 安装包核对版本、编译、自动化回归及文件校验。定向离线测试覆盖普通和 DEV 构建的 XeFG 切换、引导复用、监视器、报告和资源生命周期；Vulkan 窄路径另用真实 GPU 验证像素重放与资源释放。

此前的独立本地候选在《女鬼桥 开魂路》和《黑手党：最终版》核对了 XeFG 切换后的实际 NR 输出及未生成私有 DLL；《如龙8》的菜单切换也有独立本地实测。这些运行用的是当时的验证候选，不是此页的最终 ZIP。

### 已知限制

此更新不删除已有的 DLL 副本，不改变安装目录中的其他插件或运行时。首次加载模型仍可能短暂准备。未在最终 ZIP 上重新执行全游戏实机矩阵；动态画质、主观流畅度及其他分辨率和 FG 组合不由这些定向结果覆盖。

### 安装说明

下载 Windows x64 ZIP 和对应的 .zip.sha256 并校验。退出游戏，备份插件和设置，替换 renodx-dlss5.addon64，避免同时加载两个版本。包内有双语说明、离线 HTML 手册和许可证；支持完整 Add-on/API 18 的 ReShade 及兼容的 NVIDIA NR 运行时需另行准备。

## English

### Highlights

Ordinary Present and XeFG reuse the original signed NVIDIA NR runtime rather than creating a new private DLL copy in the game directory for those paths. This update also improves NR handoff through menus, loading screens and cutscenes, and makes the monitor and support reports follow the selected output. No new settings are required.

### Fixes

- For XeFG menus using Optional guides, as in Like a Dragon: Infinite Wealth, NR keeps prepared models when their creation requirements have not changed. Returning to play uses the current frame and still honors genuine game history resets.
- In FINAL FANTASY XV, the XeFG startup status stays gray while the first frame is pending. A real refusal or submission error is still shown. During loading, the game guides and fallback guides reuse models when their requirements match, addressing a cause of switches between original and NR frames.
- Ordinary DX11 Present in Mafia: Definitive Edition supports some cutscenes without guides by processing the current scene after composition and preserving overlays drawn afterward.
- The monitor shows NR status for its selected output and actual delivery. Support reports keep the window and status that were selected when collection began, even if the window changes afterward.
- Equivalent model parameter changes no longer reset image history. Direct3D and Vulkan use the same depth and motion calculations for ControlMask. Vulkan retains resources for replayable recordings until those recordings actually close.

### Validation

Release checks bind the build, automated regression results, version metadata and file checksums to this source and Windows x64 package. Targeted offline checks covered XeFG switching, guide reuse, monitor status, reports and resource lifetime in standard and DEV builds. The targeted Vulkan check used real GPU pixel readback to verify replay and resource release.

Separate local candidates verified NR output after XeFG switching without creating private DLL copies in The Bridge Curse: Road to Salvation and Mafia: Definitive Edition. Menu switching in Like a Dragon: Infinite Wealth was also tested on a separate local candidate. Those game tests did not use the final ZIP on this page.

### Known Limitations

Upgrading does not delete previously created DLL copies or change other add-ons or runtimes in the game directory. Initial model setup can still take a moment. The final ZIP was not retested across all games; targeted checks do not cover dynamic image quality, perceived smoothness, other resolutions or other frame generation combinations.

### Installation

Download the Windows x64 ZIP and matching .zip.sha256 and verify them. Close the game, back up your add-on and settings, and replace renodx-dlss5.addon64. Avoid loading two versions. The package contains bilingual documentation, an offline HTML manual and licenses. ReShade with full Add-on/API 18 support and a compatible NVIDIA NR runtime are separate requirements.
