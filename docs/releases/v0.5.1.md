# NR Nexus v0.5.1 — 隔帧菜单与 XeFG 载档修复 / Edit-reuse controls and XeFG loading fixes

<!-- Previous: v0.5.0 -->

[简体中文](#简体中文) · [English](#english)

## 简体中文

### 版本亮点

将已有 x2 隔帧编辑实验接入画质菜单和方案保存，并修复 XeFG 开启、载档和关闭时的 NR 交接问题。隔帧仍默认关闭，普通包的支持条件保持不变。

### 新增功能与改进

- 在**画质 → 核心画质**中直接开关**隔帧编辑复用 x2（实验）**，无需重启；随画质方案、共享预设保存，恢复默认时关闭。已有 `NREditReuse` 配置继续有效。
- 每两个基础帧刷新一次 NR 编辑，中间帧将编辑随运动应用于当前画面；x2 与 FG 输出倍率分别设置。不满足兼容条件时继续逐帧 NR，开关不会自动改动其他画质设置。具体路径和条件见[玩家指南](https://github.com/williamstosh/DLSS5-NR-Nexus/blob/v0.5.1/docs/USER_GUIDE.md#zh-edit-reuse)。

### 修复内容

- 修复在 Present 模式下开启 XeFG 或载档后 NR 可能持续没有提交、需打开菜单才恢复的问题，并恢复关闭 XeFG 后的普通 Present 处理。
- 修复关闭 XeFG 或返回普通 Present 时错误复用设备接口导致的崩溃路径。
- 消除启用 XeFG 时一次不必要的 NR 交接等待，默认离线回归覆盖相应连续输入和往返切换。

### 验证情况

本地 Release／Debug 构建、普通 Release 的诊断隔离、完整软件发布预检、UI／方案往返及中英文 Quick 离屏检查通过。软件验证使用 CPU、WARP 软件 GPU 和模型替身。既有载档修复的前一普通候选在《巫师3》用户场次中恢复持续提交；本版未另行进行游戏或动态画质验收。

### 已知限制

隔帧仅适用于指南列出的原生 DX12 Upscaled（FG 关闭）及 XeFG Present 单 Backbuffer 组合。原生 DLSS FG 隔帧仍为默认关闭的 DEV 实验，持续异步帧关联尚未完成，不在普通包开放。两条 FG 路径的生成帧最终编辑消费、动态画质与微卡顿仍待验收。XeFG 载档或开关期间仍可能出现短暂 NR 状态提示。

### 安装说明

下载 Windows x64 ZIP 和对应 `.zip.sha256` 并校验。关闭游戏、备份插件和设置，再替换 `renodx-dlss5.addon64`，避免多个有效副本并保留许可文件。另行准备支持完整 Add-on／API 18 的 ReShade 和合法取得的兼容 `nvngx_dlssnr.dll`。包内包含双语离线玩家指南，不附带厂商 Runtime、模型、SDK 或 ReShade 加载器。

## English

### Highlights

The existing x2 edit-reuse experiment now has Quality-menu and profile controls. This release also fixes NR handoffs while XeFG is enabled, saves are loaded or XeFG is disabled. Edit reuse remains off by default with the same ordinary-package requirements.

### Features & Improvements

- Toggle **x2 edit reuse (experimental)** under **Quality → Core quality** without restarting. The choice is saved with quality profiles and shared presets; restoring defaults turns it off. Existing `NREditReuse` configuration remains supported.
- Refresh the NR edit every two base frames and apply its motion-reprojected edit to the current image between refreshes. x2 is separate from the FG output multiplier. Unsupported combinations keep per-frame NR, and the toggle leaves other quality settings unchanged. See the [User Guide](https://github.com/williamstosh/DLSS5-NR-Nexus/blob/v0.5.1/docs/USER_GUIDE.md#en-edit-reuse) for paths and requirements.

### Fixes

- Fixed an issue where enabling XeFG or loading a save with Present processing could leave NR without submissions until a menu was opened, and restored ordinary Present processing after XeFG is disabled.
- Fixed a crash path caused by reusing the wrong device interface when XeFG is disabled or processing returns to ordinary Present.
- Removed an unnecessary NR handoff delay when enabling XeFG. Default offline regression now covers the related continuous input and handoff cycles.

### Validation

Local Release/Debug builds, ordinary-Release diagnostic isolation, full software release preflight, UI/profile round trips and bilingual Quick offscreen checks passed. Software validation uses CPU checks, WARP software GPU and model substitutes. The previous ordinary candidate containing the loading fixes restored sustained submissions in a user-run The Witcher 3 session. This version has no additional in-game or dynamic image-quality acceptance.

### Known Limitations

Edit reuse is limited to the native DX12 Upscaled (FG off) and XeFG Present single-Backbuffer combinations listed in the guide. Native DLSS FG edit reuse remains an off-by-default DEV experiment: continuous asynchronous frame association is incomplete and unavailable in the ordinary package. Final edited-pixel consumption by generated frames, dynamic image quality and microstutter for both FG paths still await acceptance. Brief NR status notices may still appear during XeFG loading or toggling.

### Installation

Download and verify the Windows x64 ZIP and matching `.zip.sha256`. Close the game, back up the add-on/settings, replace `renodx-dlss5.addon64`, avoid duplicate active copies and retain the licenses. Supply ReShade with full Add-on/API 18 support and a legally obtained compatible `nvngx_dlssnr.dll` separately. The package includes the bilingual offline player guide; vendor runtimes, models, SDKs and the ReShade loader are not bundled.
