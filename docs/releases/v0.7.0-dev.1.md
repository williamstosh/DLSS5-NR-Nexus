## 简体中文

### 版本亮点

新增内置更新检查和下载，在「版本与关于」查看当前版本、最新正式版、发布时间（UTC）和发布说明。经典布局入口在面板底部，现代布局在「高级 → 开发与维护」。发布说明支持基本 Markdown 排版，也可查看原文或打开发行页。

本功能属于 0.7.0-dev.1 开发版，尚未随正式安装包发布。

### 新增功能与改进

- 默认在游戏启动时自动检查，成功后冷却 24 小时，失败后冷却 1 小时。开关只影响后续自动请求，仍可手动检查。
- 更新 ZIP 保留发行文件名，默认下载到当前插件实际加载的 Add-on 目录，也可选择文件夹。下载显示进度，同名且大小一致的完整 ZIP 可直接复用，失败后可重试。
- 游戏重建图形设备时，已开始的检查和下载继续在后台运行，设备卸载无需等待网络请求结束。

### 验证情况

普通和 DEV 构建通过定向离线及配置回归，界面沿用已通过的回归结果。真实 GitHub 已验证 HTTP 200、ETag 条件请求 304、完整 ZIP 下载和已有包复用。新增离线慢请求用例覆盖卸载、立即重建和旧任务收尾顺序。《巫师 3》D3D12 复用原 DEV 候选两轮的下载、NR 切换和重启偏好验证，修复候选另以 NR 开启、自动检查开启且无冷却期冷启动，通过自动检查与偏好落盘。原生目录选择器的实机交互和玩家人工界面验收尚未完成。

### 已知限制

内置功能只检查版本和下载 ZIP，安装由玩家手动完成，NVIDIA Runtime 需单独维护。下载采用 TLS 连接验证和文件长度检查，内置下载不校验 SHA-256；已有 ZIP 按名称和长度复用。强制退出后留下的 `.nr-nexus.part` 文件需手动清理。

### 安装说明

取得 Windows x64 开发构建后，下载对应的 `.zip.sha256` 并手动校验。退出游戏，备份当前插件和设置，解压并替换实际 Add-on 目录中的 `renodx-dlss5.addon64`，然后重启游戏并核对加载版本，避免同时加载两个版本。另需支持完整 Add-on／API 18 的 ReShade 和兼容的 NVIDIA NR Runtime。

## English

### Highlights

Built-in update checks and downloads show the current version, latest stable version, publication time (UTC) and release notes under **Version & about**. Find it at the bottom of the classic layout or under **Advanced → Development & maintenance** in the modern layout. Release notes support basic Markdown formatting, with options to view the original text or open the release page.

This feature is part of the 0.7.0-dev.1 development version and has yet to ship in an official package.

### Features & Improvements

- Automatic checks run at game startup by default, with a 24-hour cooldown after success and a 1-hour cooldown after failure. The switch affects future automatic requests. Manual checks remain available.
- Update ZIPs keep their release filenames and download into the folder the current Add-on is loaded from by default. You can choose another folder. Downloads show progress, reuse a complete ZIP with the same name and size, and allow retries after failure.
- Checks and downloads already in progress continue in the background when the game rebuilds its graphics device. Device teardown does not wait for network requests to finish.

### Validation

Standard and DEV builds passed targeted offline and configuration regressions, with the previous UI regression results retained. Live GitHub checks verified HTTP 200, ETag conditional responses with HTTP 304, a complete ZIP download and reuse of an existing archive. New offline slow-response cases cover unload, immediate rebuild and completion of the old task. The Witcher 3 D3D12 download, NR toggle and preference restart results from the original two DEV runs were reused. The fixed candidate also passed a cold start with NR and automatic checks enabled and no active cooldown, including the automatic check and saved preferences. In-game interaction with the native folder picker and manual player review of the interface remain untested.

### Known Limitations

The built-in feature checks versions and downloads ZIPs. Installation is manual, and the NVIDIA runtime requires separate maintenance. Downloads use TLS connection validation and file-length checks. Built-in downloads do not verify SHA-256, and existing ZIPs are reused by name and size. Any `.nr-nexus.part` files left after a forced exit require manual cleanup.

### Installation

Once a Windows x64 development build is available, download its matching `.zip.sha256` and verify the archive manually. Exit the game, back up the current Add-on and settings, extract and replace `renodx-dlss5.addon64` in the active Add-on directory, then restart and check the loaded version. Avoid loading two versions. ReShade with full Add-on/API 18 support and a compatible NVIDIA NR runtime are separate requirements.
