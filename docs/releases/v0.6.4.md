# NR Nexus v0.6.4 — Built-in updates and smoother NR transitions

<!-- Previous: v0.6.3 -->

[English](#english) · [简体中文](#简体中文)

## English

### Highlights

Check for new releases and download update ZIPs directly from **Version & about**. This release also improves NR startup and transitions between XeFG and Present processing, and puts English before Simplified Chinese throughout the bilingual documentation.

### Features & Improvements

- View the installed version, latest stable release, publication time (UTC) and formatted release notes. Find **Version & about** at the bottom of the classic layout or under **Advanced → Development & maintenance** in the modern layout.
- Automatic checks are enabled by default. Successful checks have a 24-hour cooldown; failed checks retry after one hour. Manual checks remain available.
- Download ZIPs to the loaded Add-on's folder or choose another folder. Downloads show progress, can reuse a complete archive with the same name and size, and support retrying after failure. Installation remains manual.
- Checks and downloads continue during graphics-device rebuilds without delaying device teardown.

### Fixes

- Improves NR handoff during XeFG/menu transitions. Full-frame Present processing now waits for the current update parameters and skips scrolling or partial updates.
- Keeps the always-on monitor at its saved size when the startup window first appears.
- Restores actual NR model preparation during XeFG startup and distinguishes waiting for a recording interface from preparation that has really been submitted.
- Fixes intermittent loss of game motion vectors with two-pass detail stabilization on DX12.

### Validation

The release candidate passed the complete local software preflight, ordinary/DEV core regressions and a clean Release build. Targeted offline tests cover update download/reuse, slow requests, graphics-device rebuilds and old-task completion. The Witcher 3 D3D12 tests cover downloads, NR toggling, automatic-check cold startup and saved preferences. Like a Dragon: Infinite Wealth tests with stock ReShade confirm the saved monitor size and actual model preparation; the sampled startup capture did not detect the two startup warnings. The native folder picker and dynamic visual quality still need manual player review.

### Known Limitations

- The built-in updater downloads ZIPs only. Exit the game and replace the Add-on manually. NVIDIA NR runtimes remain a separate installation.
- Downloads use TLS and file-length checks. The built-in downloader does not verify SHA-256; existing archives are reused by filename and size. A forced exit can leave a `.nr-nexus.part` file for manual removal.
- With XeFG in Like a Dragon: Infinite Wealth, opening a menu can leave a brief consecutive group of game frames without NR before enhancement resumes. The stock ReShade host is retained. First arrival of game motion/depth data at cold startup can also rebuild NR models and skip that frame. Continuous enhancement across these moments is not claimed.

### Installation

Download the Windows x64 ZIP from this release. A matching `.zip.sha256` is available for optional verification. Exit the game, back up the current Add-on and settings, extract and replace `renodx-dlss5.addon64` in the active Add-on directory, then restart and check the loaded version. Avoid loading two versions. ReShade with full Add-on/API 18 support and a compatible NVIDIA NR runtime are required separately.

## 简体中文

### 版本亮点

现在可在「版本与关于」直接检查新版并下载更新 ZIP。本版同时改善 NR 启动与 XeFG／Present 之间的处理接续，双语文档统一调整为英文在前、简体中文在后。

### 新增功能与改进

- 查看当前安装版本、最新正式版、发布时间（UTC）和排版后的发布说明。经典布局入口在面板底部，现代布局位于「高级 → 开发与维护」。
- 默认自动检查更新，成功后冷却 24 小时，失败后间隔 1 小时重试，仍可手动检查。
- ZIP 默认下载到当前插件实际加载的目录，也可选择其他文件夹。支持进度显示、同名且大小一致的完整包复用和失败重试。安装仍由玩家手动完成。
- 图形设备重建期间，已开始的检查和下载继续运行，设备卸载无需等待网络请求结束。

### 修复内容

- 改善 XeFG 与菜单切换时的 NR 接续。普通 Present 整帧处理等待本次更新参数，滚动或局部更新时跳过处理。
- 启动窗口首次显示时，常驻监视卡保持保存的尺寸。
- 恢复 XeFG 启动阶段真实的 NR 模型准备，区分等待录制接口与已经提交的模型准备。
- 修复 DX12 双 Pass 细节稳定中游戏运动矢量偶尔丢失的问题。

### 验证情况

发布候选通过完整本地软件预检、普通／DEV 核心回归及干净 Release 构建。定向离线测试覆盖更新下载／复用、慢请求、设备重建与旧任务收尾。《巫师 3》D3D12 测试覆盖下载、NR 开关、自动检查冷启动与偏好保存。《如龙 8》在原装 ReShade 上确认了保存的监视卡尺寸与真实模型准备，启动画面采样未检出两类黄色提示。原生目录选择器与动态观感仍需玩家人工体验。

### 已知限制

- 内置更新只下载 ZIP。替换插件前须退出游戏，NVIDIA NR Runtime 仍需另行安装。
- 下载使用 TLS 和文件长度检查，不内置 SHA-256 校验；已有包按名称与大小复用。强制退出可能留下需手动删除的 `.nr-nexus.part` 文件。
- 《如龙 8》使用 XeFG 时，打开菜单后可能有短暂连续几帧未应用 NR，随后恢复。本版保留原装 ReShade。冷启动首次取得游戏运动／深度数据时也可能重建模型并跳过该帧，尚未实现这些时点的连续增强。

### 安装说明

下载本 Release 的 Windows x64 ZIP，可按需使用配套 `.zip.sha256` 校验。退出游戏，备份当前插件和设置，解压并替换实际 Add-on 目录中的 `renodx-dlss5.addon64`，然后重启并核对加载版本，避免同时加载两个版本。另需支持完整 Add-on／API 18 的 ReShade 和兼容的 NVIDIA NR Runtime。
