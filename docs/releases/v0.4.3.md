# NR Nexus v0.4.3 — 更多自适应档位与可靠准备 / More adaptive levels and reliable preparation

<!-- Previous: v0.4.1 -->

## 简体中文

### 版本亮点

自适应分辨率新增「默认」或 2–15 档选择。启用后先准备所选档位，全部就绪后再自动调节；正常切档复用已准备资源。准备过程分步推进，并改进关闭、恢复和资源清理。

### 新增功能与改进

- 继续以目标输出 FPS 操作，无需额外帧率程序。档数包含手动上限；实际不同尺寸受最低比例和取整限制，最低 67% 最多 8 档，最低 33% 最多 15 档。
- 兼容设置修改复用已有档位，减少插件自身引起的重复准备；更多档位提供更细的调节步距，同时增加首次准备时间和显存使用。
- 将首次管线准备分散到多个处理机会，减轻集中创建的阻塞；所需管线和档位完成前保留合法游戏输出。
- 开发工具新增本地控制接口和同帧区域诊断。正式 Publishing 安装包编译排除该诊断与控制路径；容量复用及少量热备实验仍默认关闭。

### 修复内容

- 修复 Render 路径准备备用档位和原生帧生成颜色处理切换描述符堆时遗留旧资源绑定的问题。
- 必需的 HUDless 输入持续缺失时暂停自动调节，避免永久停在准备状态；输入恢复后重置相应历史再恢复。
- 修复 NR 关闭时私有 FG 记录阻挡资源退休的问题，保留 GPU 完成及外部资源安全条件。
- 改进阶段设置错误提示、准备中关闭和重新启用的恢复路径，并扩展相应自动回归。

### 验证情况

已完成受影响的 CPU、严格软件 WARP／MOCK、配置事务、真实 ImGui 交互、界面快照及普通／开发构建检查。原生 NGX 工具在单颜色、单 Pass 条件下验证了默认档数和 15 档的完整准备、就绪后切档零新增资源及 OFF 清理。

《巫师 3》DX12 的游戏内验证使用 **6 档固定静态场景**，覆盖准备就绪、有限阶段往返、关闭释放，以及准备中关闭后重新启用。**未进行游戏内 15 档或动态画质验收**。真实宿主的确认弹窗 Cancel 点击未完成，现有 ImGui／配置事务测试覆盖其取消语义；该宿主输入触发问题尚未定位。

v0.4.3 Tag 流程重新执行 Publishing 构建、软件自动测试、PE 版本及打包检查；最终附件在公开前核对源码身份、诊断隔离和 SHA-256。此前实机证据对应开发候选，最终发布附件不另计为已完成游戏验收。

### 已知限制

自适应主要支持原生 DX12 单阶段及兼容的同尺寸 FG 链；跨阶段、FG 异尺寸、DX11 Bridge 和 Vulkan 继续使用手动分辨率。初次启用、模型或游戏资源变化仍可能需要准备，单次驱动／NGX 调用可能短暂停顿；显存不足时保留选择并暂停，可减少档数后重试。

游戏内自动降档／回升的动态流畅度、细节与闪烁以及实际 CG／读档恢复仍待人工验收。本版本未扩大游戏兼容性结论，也不包含隔帧编辑复用。

### 安装说明

下载 Windows x64 ZIP 与对应 `.zip.sha256` 并校验。关闭游戏，备份插件及设置，替换 `renodx-dlss5.addon64`，避免重复加载并保留许可文件。另行准备支持完整 Add-on／API 18 的 ReShade 和合法取得的兼容 `nvngx_dlssnr.dll`。安装包包含中英文离线 HTML 玩家手册，不附带厂商 Runtime、模型、SDK 或 ReShade 加载器。

## English

### Highlights

Adaptive resolution now offers Default or 2–15 levels. It prepares the selected collection before automatic adjustment begins, then reuses ready resources during normal level changes. Preparation proceeds in steps, with improved shutdown, recovery and resource cleanup.

### Features & Improvements

- Keep using a target output FPS without an extra frame-rate program. The count includes the manual upper limit. Distinct sizes depend on the minimum scale and rounding: 67% allows up to eight levels, and 33% up to fifteen.
- Compatible setting edits reuse existing levels, reducing unnecessary preparation caused by the add-on. More levels offer smaller adjustment steps at the cost of additional initial preparation time and video memory.
- Initial pipeline preparation is spread across processing opportunities to reduce concentrated blocking. Valid game output is retained until the required pipelines and levels are ready.
- Development tools add a local control interface and same-frame region diagnostics. The official Publishing package compiles out these diagnostic and control paths. Capacity-reuse and small-standby experiments remain off by default.

### Fixes

- Fixed stale resource bindings when preparing standby levels in the Render path and switching descriptor heaps for native frame-generation color processing.
- Sustained loss of required HUDless input pauses automatic adjustment instead of leaving preparation pending indefinitely. Recovery resets the relevant history before resuming.
- Fixed private FG recordings blocking resource retirement when NR is disabled, while retaining GPU-completion and external-resource safety requirements.
- Improved stage-setting error messages and recovery when disabling NR during preparation and enabling it again, with corresponding automated regression coverage.

### Validation

Affected CPU, strictly software WARP / MOCK, configuration transaction, real ImGui interaction, UI snapshot, and ordinary/development build checks passed. Independent native NGX tools validated full preparation, ready switches without new resources, and OFF cleanup for the default count and 15 levels under a single-color, single-pass contract.

In-game Witcher 3 DX12 checks used **six levels in a fixed static scene**, covering readiness, limited stage round trips, resource release, and disabling NR during preparation followed by recovery. **Fifteen levels in game and dynamic image quality were not tested.** The confirmation dialog's Cancel click was not completed in the real host; existing ImGui and configuration transaction tests cover cancellation semantics. The host input-trigger issue remains unlocated.

The v0.4.3 tag workflow reruns the Publishing build, software automated tests, PE version and packaging checks. Final assets are checked for source identity, diagnostic isolation and SHA-256 before publication. Earlier in-game evidence belongs to development candidates; the final release assets do not receive an additional in-game acceptance claim.

### Known Limitations

Adaptive sizing primarily supports native DX12 single-stage paths and compatible same-size FG chains. Cross-stage chains, mismatched FG sizes, DX11 Bridge and Vulkan retain manual resolution. Initial activation and changes to models or game resources may still require preparation. Individual driver/NGX calls can briefly stall; insufficient video memory preserves the selection and pauses adjustment, allowing a retry with fewer levels.

Dynamic in-game down/up shifts, smoothness, detail, flicker, and actual cutscene/load recovery still await manual acceptance. This release makes no broader game-compatibility claim and does not include alternate-frame editing reuse.

### Installation

Download and verify the Windows x64 ZIP and matching `.zip.sha256`. Close the game, back up the add-on/settings, replace `renodx-dlss5.addon64`, avoid duplicate active copies and keep the licenses. Supply ReShade with full add-on/API 18 support and a legally obtained compatible `nvngx_dlssnr.dll` separately. The package includes the bilingual offline HTML player guide; vendor runtimes, models, SDKs and the ReShade loader are not bundled.
