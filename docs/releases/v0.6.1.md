# NR Nexus v0.6.1 — 自适应分辨率与 XeFG 交接 / Adaptive resolution and XeFG handoff

<!-- Previous: v0.6.0 -->

## 简体中文

### 版本亮点

自适应分辨率按当前输出的可靠帧率逐档调节。使用 XeFG 时，载档和进出菜单的画面交接更可靠，同一次呈现可沿用已增强的画面。

### 新增功能与改进

- 持续低于目标帧率时，每次下降一个可用档。达到目标后保持，只有持续有余量才试升。新档完成交付并暖机后重新采样。试升失败会回到原低档，在条件改善后再尝试。
- 原生 DX11 Bridge 的合格超分后输出可用原有自适应开关。自适应与 x2 同开时，兼容上限可继续复用，真实换档先刷新。符合条件的 DX12 两档单层 B 可在低档复用，其余可用低档按逐帧处理。
- 自适应设置新增实验性资源策略：保留兼容模型、上限容量复用、上限容量按需准备。默认沿用已保存的预备方式，继续使用原档数与最低比例设置。资源策略随预设及方案槽保存，退回 v0.6.0 时保留原有方案内容。
- 符合条件的 DX11 超分后路径与原生 DLSS FG Pre-FG Present 可使用现有 x2 设置。Pre-FG 需要可靠帧身份及完整输入。同一基础帧的后续 MFG 可沿用仍有效的完整结果，输入不足时沿用该路径原有退路。

### 修复内容

- 修复 XeFG 保持开启时从 Present 切到 Render 或 Upscaled 后 NR 持续等待 DLSS 的问题。切换或停用只收尾受影响输出，保留尚未完成的 GPU 工作及其他活动输出。
- 改善 XeFG 与普通 Present 的载档和菜单交接。同一次呈现已增强的画面直接交接，避免重复增强。Optional 缺少同帧引导时处理当前画面，恢复后使用新场景的引导。冷模型先完成准备再交付颜色。
- 修复地图和菜单切换时偶发的「NR 跳过了帧但未说明原因」误报。嵌套调用、准备和 FG 使用一致的计数，真正缺少处理记录时仍会告警。
- 修复开启遮罩时 HDR 自适应备档的资源绑定。输出帧率使用可靠的游戏标签或同输出 SDK 计数，独立 Reflex 标记不再计入游戏帧数。普通 Present 仍默认每帧，旧设置和预设沿用原语义。

### 验证情况

- 普通与 DEV 构建用相同输入核对受影响的自适应、隔帧、XeFG 交接和计数。WARP＋模型替身覆盖单次增强、完整颜色／alpha、失败回退及新帧恢复。四档资源回退及部分交付合同另有原生 GPU／NVIDIA Runtime 离线证据。
- 《巫师 3》的定向实机使用带采集诊断的 DEV 候选，覆盖单 Backbuffer、Present／Optional、x2 关闭。载档、进入菜单、退出菜单的首个合法尝试都完成交付。另一次地图及菜单往返记录的 50 条累计状态均无未归账调用。两轮均正常退出并恢复原安装和设置。

### 已知限制

普通安装包包含这些生产功能。上述实机结论来自 DEV 候选的定向观测，普通包未重复该实机场景。XeFG 隔帧收益、动态画质和主观流畅度仍待验，冷档或冷模型准备可能短暂停顿。原生 DLSS FG Pre-FG Present 在《巫师 3》仍受输入交接条件限制。低档 x2 和备用资源策略有各自的模型、格式和档位条件，上限容量的少量 FP16 差异尚未作人工画质验收。

### 安装说明

下载 Windows x64 ZIP 和对应 `.zip.sha256` 并校验。退出游戏，备份插件和设置，替换 `renodx-dlss5.addon64` 并避免重复加载。包内含 README、双语 Markdown 指南、离线 HTML 手册和许可文件。另行准备支持完整 Add-on／API 18 的 ReShade 和兼容 NVIDIA NR Runtime。

## English

### Highlights

Adaptive resolution now adjusts one level at a time using reliable FPS for the current output. XeFG and ordinary Present hand off more reliably during loading and menu transitions, reusing an already enhanced picture within the same Present.

### Features & Improvements

- Sustained FPS below target steps down one available level. Reaching the target holds the level, and sustained headroom allows a trial at the next higher one. Each new level delivers a result and warms up before fresh samples guide the next decision. A failed trial returns to the prior level and can be retried when conditions improve.
- Eligible native DX11 Bridge post-SR outputs use the existing adaptive switch. With adaptive sizing and x2 enabled, the compatible upper level can keep reusing edits, and a real level change triggers a refresh. Eligible two-level DX12 paths with a single model B pass can also reuse at the lower level. Other eligible lower levels process every frame.
- Adaptive settings add experimental resource strategies for retaining compatible models, reusing upper capacity or preparing upper capacity on demand. The default follows your saved preparation mode and preserves the level count and minimum scale. Profiles and presets save the strategy, and reverting to v0.6.0 preserves existing profile contents.
- Eligible DX11 post-SR paths and native DLSS FG Pre-FG Present use the existing x2 switch. Pre-FG requires reliable frame identity and complete inputs. Later MFG calls in the same base frame can reuse a still-valid complete result. Missing inputs use the path's existing fallback.

### Fixes

- Fixed NR waiting for DLSS after switching from Present to Render or Upscaled while XeFG remains on. Switching or disabling retires the affected output while preserving unfinished GPU work and other active outputs.
- Improved XeFG and ordinary Present handoff while loading or entering and leaving menus. A picture already enhanced in the same Present is handed over without applying NR twice. Optional processes the current picture when same-frame guides are missing and uses the new scene's guides as they return. Cold models finish preparation before writing color.
- Fixed occasional false “NR skipped frames without saying why” warnings in maps and menus. Nested calls, preparation and FG use consistent accounting. A genuinely missing outcome still triggers the warning.
- Fixed resource bindings when preparing HDR adaptive levels with masking enabled. Output FPS uses reliable game tags or SDK counts for the same output. Standalone Reflex markers no longer count as game frames. Ordinary Present still defaults to Every present and preserves existing settings and presets.

### Validation

- Matching inputs in ordinary and DEV builds covered the affected adaptive sizing, edit reuse, XeFG handoff and accounting paths. WARP with model substitutes checked single enhancement, complete color and alpha, failure fallback and delivery on the next new frame. Four-level resource fallback and selected delivery contracts also have offline native GPU and NVIDIA Runtime evidence.
- Targeted Witcher 3 tests used DEV candidates with capture diagnostics, one backbuffer, Present with Optional guides and x2 off. The first eligible attempt delivered during loading, menu entry and menu exit. In a separate map and menu check, all 50 cumulative status records showed zero unaccounted calls. Both sessions exited normally and restored the original installation and settings.

### Known Limitations

The standard package includes these production features. The in-game observations above came from DEV candidates and the standard package was not separately run through those scenarios. XeFG edit-reuse performance, dynamic image quality and perceived smoothness still need validation. Preparing a cold level or model can briefly stall. Native DLSS FG Pre-FG Present remains limited by input handoff in The Witcher 3. Lower-level x2 and alternate resource strategies have specific model, format and level requirements. Small FP16 differences in upper-capacity processing still need visual review.

### Installation

Download and verify the Windows x64 ZIP and its `.zip.sha256`. Close the game, back up the add-on and settings, then replace `renodx-dlss5.addon64` and avoid duplicate loads. The package includes the README, bilingual Markdown guide, offline HTML manual and licenses. Provide ReShade with full add-on/API 18 support and a compatible NVIDIA NR Runtime separately.
